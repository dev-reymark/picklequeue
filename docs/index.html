Court Operations & Queue Management

A venue-centric web application designed for pickleball venues, open-play rotations, and tournament organizers. Built with Next.js, TypeScript, Zustand, and procedural Web Audio.

PICKLEQUEUE Operations Console Dark Mode

Drift-Free Court Timers

Calculates remaining and overtime from absolute system timestamps (endsAt - Date.now()), completely preventing timer drift when browser tabs are throttled or sleeping.

Procedural Web Audio Suite

100% synthesized sound notifications generated via Web Audio API. Includes Minimal, Standard, and Silent sound profiles with persistent milestone alert guards.

Intelligent Matchmaking

1-Click Auto-Balance evaluates waiting players across 4 skill tiers and computes the optimal 2v2 doubles split with match balance percentage scoring.

Queue & Post-Match Rotations

Configurable FIFO or skill-balanced queue staging with 1-click court dispatch and flexible post-game workflows (Return to Pool, Requeue, Resting, or Check Out).

Local Persistence & Backup

All players, courts, queues, and settings persist automatically in localStorage with complete JSON backup export and restore capabilities.

Zero Emojis & Component Architecture

Clean, professional venue layout with semantic status indicators and modular UI primitives under src/components/ui/.
